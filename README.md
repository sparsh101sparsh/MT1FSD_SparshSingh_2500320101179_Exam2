A REST API developed with Node.js and Express.js for managing a library book catalog using an in-memory JavaScript array.

## Requirements and Record Structure

Each book record contains the following properties:

| Field | Type | Description |
|---|---|---|
| id | Number | Unique identifier generated by the server |
| title | String | Title of the book |
| author | String | Name of the author |
| genre | String | Category or genre of the book |
| publishedYear | Number | Year of publication |
| available | Boolean | Availability status |

## API Endpoints

### 1. Get all books
- Method: `GET`
- Route: `/api/books`
- Response: Status 200 with an array of all book records.

### 2. Filter books by author
- Method: `GET`
- Route: `/api/books/filter?author=value`
- Response: Status 200 with matching records (case-insensitive search). If no records match, returns an empty array with status 200. Returns status 400 if the author query parameter is missing.
- Note: This route is registered before `/api/books/:id` so the word `filter` is not matched as a parameter.

### 3. Get book by ID
- Method: `GET`
- Route: `/api/books/:id`
- Response: Status 200 with the matching book record, or status 404 if the book does not exist.

### 4. Create a new book
- Method: `POST`
- Route: `/api/books`
- Body:
```json
{
  "title": "The Discovery of India",
  "author": "Jawaharlal Nehru",
  "genre": "History",
  "publishedYear": 1946,
  "available": true
}
```
- Response: Status 201 with the created record and generated numeric ID. Returns status 400 if required fields are missing or have invalid types.

### 5. Update an existing book
- Method: `PUT`
- Route: `/api/books/:id`
- Body:
```json
{
  "title": "The Alchemist - Revised Edition",
  "author": "Paulo Coelho",
  "genre": "Fiction",
  "publishedYear": 1988,
  "available": true
}
```
- Response: Status 200 with the updated record, status 404 if the book is not found, or status 400 for an invalid payload.

### 6. Delete a book
- Method: `DELETE`
- Route: `/api/books/:id`
- Response: Status 200 with a success message and the deleted record, or status 404 if the book does not exist.

## Testing

Automated test cases verify:
- Retrieving all initial records (status 200)
- Filtering by author with valid matching author and non-matching author (status 200)
- Missing author query on filter (status 400)
- Fetching by valid ID (status 200) and missing ID (status 404)
- Creating new records with validation (status 201) and invalid payloads (status 400)
- Updating records (status 200) and updating missing IDs (status 404)
- Deleting records (status 200) and confirming deletion on subsequent requests (status 404)

You can also test the endpoints using:
